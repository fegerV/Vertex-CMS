# Настройка AI RAG Консультанта

## Обзор

AI RAG (Retrieval-Augmented Generation) Консультант — это интеллектуальная система поддержки пользователей, которая отвечает на вопросы на основе вашей базы знаний. Система использует векторный поиск и языковые модели для генерации точных ответов.

## Архитектура системы

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ Пользователь│ ──▶ │  RAG Chat    │ ──▶ │   OpenAI    │
│   (вопрос)  │     │   Service    │     │    API      │
└─────────────┘     └──────────────┘     └─────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │  Embedding   │
                    │   Service    │
                    └──────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
     ┌─────────────────┐      ┌─────────────────┐
     │   Supabase      │      │  Local MySQL    │
     │  (векторный     │      │  (fallback)     │
     │   поиск)        │      │                 │
     └─────────────────┘      └─────────────────┘
```

**Компоненты:**

1. **RagChatService** — обрабатывает запросы пользователей
2. **EmbeddingService** — генерирует векторные представления текста
3. **SupabaseVectorService** — работает с векторной базой данных Supabase
4. **DocumentProcessorService** — разбивает документы на чанки

## Настройка API ключей

### Шаг 1: Получение OpenAI API Key

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел **API Keys**
3. Нажмите **Create new secret key**
4. Скопируйте ключ (начинается с `sk-`)
5. Сохраните ключ в надежном месте

### Шаг 2: Настройка в админ-панели

1. Перейдите в **SEO → AI Knowledge Base → Настройки**
2. В секции **API Настройки** заполните:
   - **OpenAI API Key**: вставьте ваш ключ `sk-...`
   - **Модель для эмбеддингов**: выберите `text-embedding-ada-002` (рекомендуется)
   - **Модель для чата**: выберите `gpt-3.5-turbo` (быстро и дешево) или `gpt-4` (точнее)
   - **Температура**: установите `0.3` для точных ответов

### Шаг 3: Проверка подключения

1. Нажмите кнопку **Проверить соединение**
2. Индикатор статуса должен измениться на **Подключено**

**Текущий статус отображается в правой панели:**
- 🟢 **Настроен** — ключ действителен
- 🟡 **Не настроен** — ключ не введен
- 🔴 **Ошибка** — неверный ключ или проблемы с доступом

## Интеграция с Supabase

### Что такое Supabase?

Supabase — это облачная платформа, предоставляющая PostgreSQL с расширением pgvector для быстрого векторного поиска. Использование Supabase ускоряет поиск релевантных чанков в 10-100 раз по сравнению с локальным поиском.

### Шаг 1: Создание проекта Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com)
2. Создайте новый проект:
   - Выберите регион (ближайший к вашим пользователям)
   - Задайте пароль для базы данных
3. Дождитесь завершения развертывания (~2 минуты)

### Шаг 2: Установка расширения pgvector

1. В панели Supabase перейдите в **Database → Extensions**
2. Найдите расширение **vector**
3. Нажмите **Enable**
4. Подтвердите установку

### Шаг 3: Получение учетных данных

1. Перейдите в **Settings → API**
2. Скопируйте:
   - **Project URL** (например: `https://xxxxx.supabase.co`)
   - **anon/public key** (начинается с `eyJ...`)

### Шаг 4: Настройка в CMS

1. Вернитесь в **SEO → AI Knowledge Base → Настройки**
2. Заполните поля Supabase:
   - **Supabase URL**: вставьте Project URL
   - **Supabase API Key**: вставьте anon key
3. Нажмите **Сохранить настройки**

### Шаг 5: Запуск миграций

Выполните команду для создания необходимых таблиц:

```bash
php artisan migrate
```

Это создаст:
- Расширение vector в PostgreSQL
- Индексы IVFFlat для ускорения поиска
- RPC функцию `search_kb_chunks()` для векторного поиска

### Шаг 6: Обработка существующих документов

Если у вас уже есть документы в базе знаний:

```bash
# Перегенерировать эмбеддинги для всех чанков
php artisan ai:process-chunks
```

Или через админ-панель:
1. Перейдите в **База знаний**
2. Нажмите **Перегенерировать все эмбеддинги**

## Управление базой знаний

### Добавление документов

1. Перейдите в **SEO → AI Knowledge Base**
2. Нажмите **Добавить документ**
3. Заполните форму:
   - **Заголовок**: краткое название документа
   - **Категория**: выберите из списка или создайте новую
   - **Содержимое**: текст документа (или загрузите файл)
4. Нажмите **Сохранить**

**Автоматическая обработка:**
После сохранения документ автоматически:
- Разбивается на чанки (оптимально 400-600 символов)
- Генерируются векторные эмбеддинги
- Индексируется для поиска

### Рекомендуемая структура базы знаний

**Категории:**
- Часто задаваемые вопросы (FAQ)
- Условия доставки и оплаты
- Информация о продуктах
- Технические характеристики
- Гарантийное обслуживание
- Контакты и поддержка

**Форматирование документов:**
- Используйте четкие заголовки
- Разбивайте текст на логические блоки
- Избегайте слишком длинных предложений
- Включайте конкретные факты и цифры

### Обновление документов

1. Найдите документ в списке
2. Нажмите **Редактировать**
3. Внесите изменения
4. Нажмите **Сохранить**
5. При необходимости нажмите **Пересоздать чанки**

## Настройка виджета чата

### Параметры виджета

В разделе **Настройки виджета** вы можете настроить:

| Параметр | Описание | Пример |
|----------|----------|--------|
| Заголовок виджета | Название в шапке чата | "Онлайн-помощник" |
| Приветственное сообщение | Первое сообщение пользователю | "Здравствуйте! Чем могу помочь?" |
| Цвет виджета | Основной цвет интерфейса | #4f46e5 (синий) |
| Позиция | Расположение на странице | Правый нижний угол |
| Статус | Включен/выключен | ✓ Включен |

### Установка виджета на сайт

После настройки добавьте код виджета в шаблон вашего сайта перед закрывающим тегом `</body>`:

```blade
<x-ai-chat.widget 
    title="Помощник"
    color="#4f46e5"
    position="right"
/>
```

Или для Laravel Blade:

```blade
@include('components.ai-chat-widget', [
    'title' => 'Онлайн-консультант',
    'color' => '#4f46e5',
    'position' => 'right'
])
```

### Продвинутые настройки

**Максимум чанков для поиска** (рекомендуется: 5)
- Сколько фрагментов текста использовать для ответа
- Больше = более полный ответ, но дороже
- Меньше = быстрее и дешевле

**Минимальная релевантность** (рекомендуется: 30%)
- Порог схожести найденных фрагментов
- Если ниже — AI сообщит что не знает ответа
- Защищает от неточных ответов

**Размер чанка** (рекомендуется: 500 символов)
- Оптимально 400-600 символов
- Меньше = больше чанков, точнее поиск
- Больше = меньше чанков, шире контекст

## Troubleshooting

### Эмбеддинги не генерируются

**Проблема:** Документы не обрабатываются

**Решение:**
1. Проверьте наличие `OPENAI_API_KEY` в `.env`
2. Убедитесь что ключ действителен
3. Проверьте лимиты токенов в аккаунте OpenAI
4. Посмотрите логи на наличие ошибок

### Медленный поиск

**Проблема:** Поиск занимает более 1 секунды

**Причины:**
- Не настроен Supabase (используется PHP fallback)
- Нет индекса IVFFlat
- Большая база чанков (>10000)

**Решение:**
1. Настройте Supabase (см. выше)
2. Запустите миграции повторно
3. Проверьте наличие индексов

### Ошибка "extension 'vector' does not exist"

**Решение:**
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

Или через панель Supabase: **Database → Extensions → vector → Enable**

### Ошибка "permission denied"

**Причина:** Используется неправильный ключ Supabase

**Решение:**
- Для REST API нужен `anon` ключ (публичный)
- Не используйте `service_role` ключ на фронтенде

## Безопасность

**Важные рекомендации:**

1. **Хранение ключей:**
   - Никогда не коммитьте `.env` файл в git
   - Используйте разные ключи для dev/prod окружений
   - Регулярно обновляйте ключи

2. **Ограничение доступа:**
   - Только авторизованные администраторы должны иметь доступ к настройкам
   - Используйте role-based permissions

3. **Мониторинг расходов:**
   - Установите лимиты в аккаунте OpenAI
   - Отслеживайте использование токенов
   - Настройте уведомления о превышении бюджета
