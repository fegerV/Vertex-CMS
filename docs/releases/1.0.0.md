# VertexCMS 1.0.0

First stable core compatibility baseline.

## Highlights

- Stable API v1 response and error policy.
- Public module, settings, cache invalidation and backup hook contracts.
- Versioned settings export/import with secrets excluded by default.
- Installer validation and generic failure responses that do not disclose internal credentials.
- Documented installation, configuration, module development and upgrade process.

## Upgrade notes

Set `VERTEX_VERSION=1.0.0` when overriding the default. Follow `docs/upgrade-guide.md`, run all migrations, clear caches, and validate third-party modules against the public 1.x contracts. No manual database edits are required.
