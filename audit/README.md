## 🔐 Исправления безопасности

### C01: SQL Injection
**До:** Пароль БД передавался через аргумент командной строки `-p${password}`  
**После:** Используется временный файл опций с правами `0600`

### C02: SSRF
**До:** Однократная валидация IP при создании webhook  
**После:** Двухэтапная валидация + повторная проверка перед запросом + кэш на 5 минут

### C04: Hardcoded Data
**До:** `'Телефон: 8-800-XXX-XX-XX'` в коде  
**После:** Конфигурация через `config('vertex.contacts.phone')`
