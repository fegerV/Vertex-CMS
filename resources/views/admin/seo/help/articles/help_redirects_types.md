# Типы редиректов (301 vs 302)

**Редирект** (переадресация) — это механизм перенаправления пользователя и поисковых систем с одного URL на другой.

## Основные типы редиректов

### 301 — Постоянное перемещение (Moved Permanently)

Используется, когда страница была **навсегда** перемещена на новый адрес.

**Когда применять:**
- Удаление страницы с переносом контента на новую
- Смена доменного имени сайта
- Объединение дублирующихся страниц
- Исправление структуры URL (с http на https, с www на без www)

**Влияние на SEO:**
- ✅ Передает 90-99% ссылочного веса (Link Juice)
- ✅ Поисковики заменяют старый URL на новый в индексе
- ✅ Сохраняет позиции и трафик в долгосрочной перспективе

**Пример использования:**
```
Старый URL: /old-product.html
Новый URL: /new-product.html
Тип: 301 (Постоянный)
```

### 302 — Временное перемещение (Found / Moved Temporarily)

Используется для **временных** изменений, когда планируется возврат к исходному URL.

**Когда применять:**
- Временная недоступность страницы (технические работы)
- A/B тестирование разных версий страницы
- Сезонные акции и промо-страницы
- Геотаргетинг (временное перенаправление по региону)

**Влияние на SEO:**
- ⚠️ Не передает полный ссылочный вес
- ⚠️ Старый URL остается в индексе поисковых систем
- ⚠️ Может вызвать путаницу у поисковых роботов при длительном использовании

**Пример использования:**
```
Старый URL: /product.html
Временный URL: /product-out-of-stock.html
Тип: 302 (Временный)
```

## Сравнительная таблица

| Параметр | 301 Редирект | 302 Редирект |
|----------|--------------|--------------|
| **Назначение** | Постоянное перемещение | Временное перемещение |
| **Передача веса** | 90-99% | 0-50% (не гарантируется) |
| **Индексация** | Новый URL заменяет старый | Старый URL остается в индексе |
| **Кэширование** | Кэшируется браузером надолго | Кэшируется ненадолго |
| **SEO эффект** | Положительный при правильном использовании | Нейтральный/Рискованный |

## Частые ошибки

### ❌ Использование 302 вместо 301
Если вы навсегда переместили страницу, но поставили 302, поисковики не передадут вес новой странице.

### ❌ Цепочки редиректов
Избегайте схем: `A → B → C`. Лучше сделать `A → C` напрямую.

### ❌ Циклические редиректы
Ошибка: `A → B → A`. Приводит к ошибке "Too Many Redirects".

### ❌ Редирект на нерелевантную страницу
Перенаправление главной категории на несвязанный товар ухудшает пользовательский опыт.

## Практические рекомендации

1. **Всегда используйте 301** при удалении или постоянном перемещении контента.
2. **Проверяйте цепочки** с помощью инструмента мониторинга 404 ошибок.
3. **Обновляйте внутренние ссылки** на сайте, чтобы они указывали сразу на новый URL.
4. **Мониторьте логи** после настройки редиректов на предмет ошибок.
5. **Используйте регулярные выражения** для массовых перенаправлений по шаблону.

## Примеры настройки в Vertex SEO Pro

### Простой редирект
```
Откуда: /old-page
Куда: /new-page
Тип: 301
```

### Редирект с параметрами
```
Откуда: /product?id=123
Куда: /products/new-product-name
Тип: 301
```

### Массовый редирект через Regex
```
Откуда: ^/category/(.*)$
Куда: /new-category/$1
Тип: 301
```

> **Важно**: После создания редиректа обязательно проверьте его работу в режиме инкогнито браузера и убедитесь, что старый URL корректно перенаправляется на новый.
