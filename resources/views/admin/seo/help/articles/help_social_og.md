# Что такое Open Graph

**Open Graph (OG)** — это протокол, разработанный Facebook, который позволяет веб-сайтам контролировать, как их контент отображается при публикации ссылок в социальных сетях.

## Зачем нужен Open Graph

Без разметки Open Graph социальные сети автоматически определяют заголовок, описание и изображение для превью ссылки, что часто приводит к некорректному отображению:
- ❌ Обрезанные заголовки
- ❌ Неподходящие изображения (логотипы, баннеры)
- ❌ Случайный текст из контента вместо описания

С правильно настроенным Open Graph вы получаете:
- ✅ Привлекательные превью с нужным изображением
- ✅ Четкие заголовки и описания
- ✅ Увеличение CTR (кликабельности) на 20-50%
- ✅ Профессиональный вид бренда в соцсетях

## Основные мета-теги Open Graph

### Обязательные теги

```html
<!-- Основной URL страницы -->
<meta property="og:url" content="https://yoursite.com/page-url" />

<!-- Тип контента -->
<meta property="og:type" content="website" />

<!-- Заголовок для соцсетей -->
<meta property="og:title" content="Привлекательный заголовок страницы" />

<!-- Описание для соцсетей -->
<meta property="og:description" content="Краткое описание содержания страницы" />

<!-- Изображение для превью (минимум 1200x630px) -->
<meta property="og:image" content="https://yoursite.com/images/preview.jpg" />
```

### Дополнительные теги

```html
<!-- Название сайта -->
<meta property="og:site_name" content="Название Вашего Сайта" />

<!-- Локаль (язык и регион) -->
<meta property="og:locale" content="ru_RU" />

<!-- Альтернативные изображения (галерея) -->
<meta property="og:image:alt" content="Описание изображения" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />

<!-- Видео контент -->
<meta property="og:video" content="https://yoursite.com/video.mp4" />
<meta property="og:video:type" content="video/mp4" />
```

## Типы контента (og:type)

| Тип | Описание | Пример использования |
|-----|----------|---------------------|
| `website` | Обычная страница сайта | Главная, категории |
| `article` | Статья, новость, пост в блоге | Публикации с датой и автором |
| `product` | Товар интернет-магазина | Карточки товаров с ценой |
| `profile` | Профиль пользователя | Страницы авторов |
| `video` | Видеоконтент | Видеоуроки, записи вебинаров |

## Требования к изображениям

Для лучшего отображения в разных социальных сетях:

### Facebook / VK
- **Рекомендуемый размер**: 1200 x 630 пикселей
- **Минимальный размер**: 600 x 315 пикселей
- **Соотношение сторон**: 1.91:1
- **Формат**: JPG или PNG
- **Вес файла**: до 8 МБ

### Twitter (Twitter Cards)
- **Summary Card**: 120 x 120 px (минимум)
- **Summary Card with Large Image**: 1200 x 600 px
- **Соотношение**: 1:1 или 2:1

### LinkedIn
- **Размер**: 1200 x 627 пикселей
- **Соотношение**: 1.91:1

## Настройка в Vertex SEO Pro

### Глобальные настройки

Перейдите в **SEO → Соцсети (OG)** и настройте:

1. **Заголовок по умолчанию** — шаблон для всех страниц
   - Пример: `{title} | {sitename}`

2. **Описание по умолчанию** — автогенерируемое описание
   - Пример: Первые 160 символов контента

3. **Изображение по умолчанию** — логотип или брендовая картинка
   - Загружается в разделе "OG Image"

4. **Профили соцсетей** — ссылки на официальные страницы
   - Facebook, VK, Instagram, YouTube, Telegram

### Индивидуальные настройки для страниц

При редактировании каждой страницы вы можете:
- Переопределить глобальные настройки
- Загрузить уникальное OG-изображение
- Настроить превью в реальном времени

## Предпросмотр в социальных сетях

Используйте встроенный инструмент предпросмотра в Vertex SEO Pro:

1. Откройте редактор страницы
2. Перейдите во вкладку "Социальные сети"
3. Введите заголовок и описание
4. Загрузите изображение
5. Посмотрите, как ссылка будет выглядеть в:
   - Facebook / VK
   - Twitter
   - LinkedIn

## Тестирование и отладка

После настройки проверьте корректность разметки:

- **Facebook Sharing Debugger**: https://developers.facebook.com/tools/debug/
- **Twitter Card Validator**: https://cards-dev.twitter.com/validator
- **LinkedIn Post Inspector**: https://www.linkedin.com/post-inspector/

> **Важно**: После изменений в разметке используйте кнопки "Scrape Again" или "Refresh" в инструментах отладки, чтобы социальные сети обновили кэш превью.

## Частые ошибки

### ❌ Слишком маленькое изображение
Результат: Изображение не отображается или обрезается

### ❌ Длинный заголовок (>90 символов)
Результат: Заголовок обрезается с многоточием

### ❌ Отсутствие изображения
Результат: Соцсеть выбирает случайную картинку со страницы

### ❌ Неверный тип контента
Результат: Неправильное отображение дополнительных полей (цена, автор, дата)

## Лучшие практики

1. **Уникальные изображения** для важных страниц (товары, статьи)
2. **Текст на изображении** должен быть читаемым в миниатюре
3. **A/B тестирование** разных изображений для повышения CTR
4. **Актуальность** — обновляйте OG-данные при изменении контента
5. **Консистентность** — единый стиль оформления для всего сайта
